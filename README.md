# Schulplaner

Handy-App zum Schulplaner: zeigt den Wochenplan, den Fortschritt und den Rückblick einer Lernwoche.

- Die App enthält keine persönlichen Daten. Der Plan kommt als Wochenpaket-Datei aufs Gerät.
- Alle Eintragungen bleiben auf dem Gerät und werden als Rückmeldung-Datei zurückgegeben.
- Kein Server, keine Anmeldung, keine Auswertung durch Dritte.

Öffnen: https://rinasgithub.github.io/Schulplaner/
